## 🔧 Troubleshooting

### ❓ Mi sitio muestra un 404
**Solución**: Verifica que GitHub Pages está activado en Settings → Pages

### ❓ Los cambios no se ven
**Solución**: 
1. Espera 30 segundos
2. Recarga la página (Ctrl+F5 en Windows, Cmd+Shift+R en Mac)
3. Verifica que hiciste `git push`

### ❓ Mi dominio no apunta correctamente
**Solución**:
1. Verifica los registros DNS en tu hosting (Hostinger)
2. Espera 24-48 horas para propagación
3. Usa https://dns.google/ para verificar
